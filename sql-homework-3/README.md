
## 1. Назва датасету

**NYC Yellow Taxi Trip Records**

Датасет містить інформацію про поїздки жовтого таксі в Нью-Йорку, зокрема час початку та завершення поїздки, кількість пасажирів, відстань, місця посадки й висадки, спосіб оплати та вартість.

## 2. Офіційне джерело

**NYC Taxi & Limousine Commission (TLC)**

Офіційне джерело: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

Дані за січень 2025 року — `yellow_tripdata_2025-01.parquet`.

## 3. Формування вибірки

Для виконання домашнього завдання використано вибірку з **50 000 записів** датасету NYC Yellow Taxi за січень 2025 року.

Дані завантажено до PostgreSQL у два етапи:

1. Імпорт сирих даних до staging-таблиці `hw3_data_staging`.
2. Перетворення типів даних, очищення та перенесення записів до фінальної таблиці `hw3_taxi_trips` за допомогою `INSERT INTO ... SELECT`.

Для аналізу використано SQL-запити в Jupyter Notebook (`homework3.ipynb`).

## 4. Кількість рядків

| Таблиця | Кількість рядків |
|---|---:|
| `hw3_data_staging` | 50 000 |
| `hw3_taxi_trips` | 50 000 |

Після очищення кількість записів не змінилася. Усі 50 000 рядків були перенесені до фінальної типізованої таблиці.

## 5. Використані технології

- PostgreSQL — зберігання та обробка даних.
- SQL — очищення, перевірка якості та аналіз даних.
- Jupyter Notebook — виконання запитів і документування результатів.
- Python — налаштування підключення до бази даних та імпорт датасету.
